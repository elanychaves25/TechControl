TechControl

Sistema de Controle de Empréstimo de Equipamentos Escolares

Bem-vindo ao TechControl!

O TechControl é um sistema desenvolvido para auxiliar no controle de empréstimos de equipamentos escolares.

Utilize o menu para cadastrar equipamentos, controlar usuários, registrar empréstimos, registrar devoluções e consultar o histórico.

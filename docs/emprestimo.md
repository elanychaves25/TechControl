# Registro de Empréstimo

## Objetivo

Registrar o empréstimo de um equipamento no sistema TechControl.

## Informações do empréstimo

| Equipamento | Usuário responsável | Data de retirada |
|---|---|---|
| Notebook (EQ001) | Elany | 26/08/2026 |
| Projetor (EQ002) | Rayca | 26/08/2026 |

## Funcionamento

O registro do empréstimo deve informar qual equipamento foi retirado, quem é o usuário responsável e a data em que ocorreu a retirada.

Após o registro, a situação do equipamento deverá ser atualizada para **Emprestado**.

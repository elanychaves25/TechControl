# Consulta de Equipamentos

## Objetivo

Permitir visualizar os equipamentos cadastrados no sistema TechControl e verificar a situação de cada equipamento.

## Equipamentos consultados

| Identificação | Nome | Situação |
|---|---|---|
| EQ001 | Notebook | Disponível |
| EQ002 | Projetor | Indisponível |
| EQ003 | Tablet | Emprestado |
| EQ004 | Caixa de som | Emprestado |
| EQ005 | Computador | Disponível |

## Situações disponíveis

Os equipamentos podem apresentar as seguintes situações:

- Disponível
- Emprestado
- Indisponível

A consulta permite identificar a situação atual de cada equipamento cadastrado.

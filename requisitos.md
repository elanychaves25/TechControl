# Requisitos do Sistema

 1. Introdução
O TechControl é um sistema desenvolvido para auxiliar no controle de empréstimos de equipamentos escolares.

 2. Objetivo
O sistema tem como objetivo organizar o cadastro, empréstimo e devolução de equipamentos, facilitando o controle de sua utilização.
 
 3. Usuários do sistema

- Alunos;
- Professores;
- Responsáveis pelo controle dos equipamentos.

 4. Requisitos Funcionais
 RF01 - Cadastro de equipamentos

O sistema deve permitir o cadastro dos equipamentos disponíveis na instituição.

 RF02 - Consulta de equipamentos
O sistema deve permitir consultar os equipamentos cadastrados e verificar sua disponibilidade.

 RF03 - Registro de empréstimo
O sistema deve permitir registrar o empréstimo de um equipamento, informando o usuário responsável e a data da retirada.

RF04 - Registro de devolução
O sistema deve permitir registrar a devolução de um equipamento.

RF05 - Controle de situação
O sistema deve informar se o equipamento está disponível, emprestado ou indisponível.

RF06 - Histórico
O sistema deve permitir consultar o histórico de empréstimos e devoluções.

 5. Requisitos Não Funcionais
  RNF01 - Usabilidade
O sistema deve possuir uma interface simples e fácil de utilizar.
 RNF02 - Organização

As informações dos equipamentos e empréstimos devem ser organizadas de forma clara.

 RNF03 - Segurança

O acesso às informações do sistema deve ser controlado de acordo com o tipo de usuário.

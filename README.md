# TechControl

## Sistema de Controle de Empréstimo de Equipamentos Escolares

### Sobre o projeto

O TechControl é um sistema desenvolvido para facilitar o controle de empréstimos de equipamentos em instituições de ensino.

O sistema permite registrar os equipamentos disponíveis, controlar os empréstimos e devoluções e consultar o histórico de utilização.

### Problema

Em uma instituição de ensino, pode ser difícil controlar quais equipamentos estão disponíveis, quem está utilizando cada equipamento e quando eles devem ser devolvidos.

### Solução

O TechControl busca organizar esse processo por meio de um sistema que permita cadastrar equipamentos, registrar empréstimos e devoluções e acompanhar a situação dos equipamentos.

### Objetivo

Facilitar o gerenciamento dos equipamentos escolares, tornando o processo de empréstimo mais organizado e permitindo um melhor acompanhamento dos equipamentos.

### Funcionalidades

- Cadastro de equipamentos;
- Consulta de equipamentos disponíveis;
- Registro de empréstimos;
- Registro de devoluções;
- Consulta do histórico de empréstimos;
- Controle da situação dos equipamentos.

### Público-alvo

O sistema será destinado a alunos, professores e responsáveis pelo controle dos equipamentos da instituição.
